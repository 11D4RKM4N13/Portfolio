## Why Astro

Astro outputs static HTML by default and only ships JavaScript where it's needed, which makes the site very fast.

## Features

- Content managed with Markdown *content collections*.
- Bilingual (Spanish / English) with `hreflang` tags and a per-language sitemap.
- Light/dark mode that follows the system preference.
- Page transitions, RSS and sitemap.
